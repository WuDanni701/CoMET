**CoMET** is a cohort-adaptive multi-omics multi-task learning framework for predicting objective response to immune checkpoint blockade (ICB) across heterogeneous patient cohorts.

The implementation integrates transcriptomic representations learned from TCGA, cohort-shared clinical/genomic covariates, cohort-specific variables, and a Multi-gate Mixture-of-Experts (MMoE) backbone with cohort-specific prediction heads.

> The source-code module is retained under the historical `ICIMTL/` directory name for compatibility with the original implementation.

---

## Overview

CoMET jointly models four independent ICB cohorts:

- **DavidA**
- **DavidLiu**
- **Ravi**
- **IMvigor210**

The framework combines:

- RNA-seq latent representations generated by a TCGA-pretrained autoencoder;
- shared covariates, including sex and tumor mutational burden (TMB);
- cohort-specific clinical, genomic, and transcriptomic-derived variables;
- an MMoE backbone for cross-cohort knowledge sharing; and
- cohort-specific gated prediction heads for adaptive response prediction.

Model performance is evaluated using five-fold stratified cross-validation. Conventional baselines and multiple ablation settings are included for comparison.

---

## Key Features

- **Cohort-adaptive multi-task learning**  
  Each ICB cohort is treated as a related prediction task while retaining cohort-specific information.

- **Multi-omics integration**  
  Transcriptomic, genomic, and clinical features are integrated within a unified model.

- **TCGA-based transfer learning**  
  A pretrained RNA encoder and compatible shared-encoder parameters are transferred from TCGA-derived pretraining artifacts.

- **MMoE-based shared representation learning**  
  Multiple experts and task-specific gates enable knowledge sharing across heterogeneous cohorts.

- **Cohort-specific gated prediction heads**  
  Shared MMoE representations are adaptively fused with cohort-specific features.

- **Leakage-aware preprocessing**  
  Clinical preprocessing parameters are estimated from training folds and applied unchanged to corresponding validation samples.

- **Five-fold cross-validation**  
  Folds are jointly stratified by cohort and response label.

- **Baseline and ablation comparisons**  
  Logistic regression, XGBoost, neural network baselines, and several learning/architecture ablations are provided.

- **Reproducible outputs**  
  Out-of-fold predictions and best-performing fold checkpoints are saved for downstream analyses.

## Model Architecture

### RNA representation

The pretrained autoencoder transforms the selected RNA-seq features into a compact latent representation. During the main ICB experiment, the pretrained encoder is used in evaluation mode to generate RNA latent features.

### Shared MMoE encoder

The shared input combines:

```text
RNA latent representation + Sex_F + Sex_M + TMB
```

The MMoE module contains shared experts and cohort-specific gates. Each cohort receives a task-specific mixture of expert representations.

### Cohort-specific prediction heads

Each cohort has an independent prediction head. The head:

1. projects the shared MMoE representation;
2. encodes cohort-specific features;
3. learns a gating coefficient for adaptive fusion; and
4. outputs the final response logit.

This design allows shared cross-cohort learning while preserving cohort-specific information.

---

## Preprocessing

### RNA preprocessing

RNA expression is standardized using cohort-matched TCGA-derived scaling parameters stored in:

```text
TCGA_pretraining/std_scaler.joblib
```

The predefined selected genes are then extracted and passed through the pretrained RNA encoder.

### Clinical preprocessing

Fold-specific preprocessing is performed using training data only.

For continuous clinical variables:

- missing values are imputed using the training-fold median;
- values are scaled using `RobustScaler`;
- fitted transformations are applied unchanged to validation samples.

For supported categorical one-hot groups, missing groups are imputed using the modal training-fold category.

This procedure avoids using validation-set information when estimating preprocessing parameters.

## Training

The main training procedure is implemented in:

```text
ICIMTL/compare_with_baselinemodel.py
```

Five-fold cross-validation is performed using joint cohort-response stratification:

```python
StratifiedKFold(
    n_splits=5,
    shuffle=True,
    random_state=269
)
```

The current main entry point uses:

```python
five_fold_cross_validation(freeze_shared=True)
```

Under this setting:

- compatible pretrained shared-encoder parameters are loaded;
- pretrained expert parameters are frozen during ICB training;
- shared MMoE gates and cohort-specific components remain trainable;
- cohort-specific class weights are estimated from each training fold; and
- model selection is based on mean validation AUROC across tasks.

The main implementation uses a fixed random seed of:

```text
269
```

## Ablation Experiments

Additional experiments are provided under:


They evaluate the contribution of major CoMET components and learning strategies.


Retains the shared MMoE backbone and cohort-specific prediction heads while excluding cohort-specific input and gated-fusion branches.

### Single-cohort modeling


Trains an independent DNN for each cohort instead of jointly learning across cohorts.


```text
ablation/pooled/
```

Pools all cohorts into a single prediction task and uses shared inputs only.

Run with:

```bash
python ablation/pooled/train.py
```

### Without MMoE

```text
ablation/without_mmoe/
```

Replaces the MMoE shared representation module with a shared DNN while retaining the downstream cohort-specific prediction framework.

### Without TCGA pretraining

```text
ablation/without_pretraining/
```


```bash
python ICIMTL/compare_with_baselinemodel.py
```

1. loads the processed ICB data;
2. loads TCGA-derived preprocessing and pretrained model artifacts;
3. generates RNA latent features;

6. trains CoMET;
7. trains the three conventional baseline models;
8. evaluates predictive performance; and
9. saves out-of-fold predictions and trained checkpoints.
